LETTA CLOUD SETUP - QUICK REFERENCE
================================================================================

THE TOOL: mcp_http_proxy.py (HTTP REST API for Letta Cloud)

STEP 1: Start HTTP Proxy
-------------------------
cd /home/kobros-tech/workspace/zenoo-rpc/zenoo-rpc
./scripts/start_http_proxy.sh

STEP 2: Expose with ngrok
--------------------------
ngrok http 8080

Copy the HTTPS URL (e.g., https://abc123.ngrok.io)

STEP 3: Configure in Letta Cloud (https://app.letta.ai/)
---------------------------------------------------------
Settings → MCP Servers → Add Server

  Name:    zenoo-odoo
  URL:     https://abc123.ngrok.io  ← Your ngrok URL
  Auth:    Bearer Token
  Token:   letta-secret-123

STEP 4: Create Agent
--------------------
Agents → Create → Select "zenoo-odoo" MCP Server → Enable tools
